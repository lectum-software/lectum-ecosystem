# Regras do projeto

- Esse projeto é um monorepo que será publicado separadamente em produção, eles estão unificados apenas para facilitar o desenvolvimento.

# Ao receber links do Figma:
- Nunca tente abrir via navegador, curl, wget ou fetch.
- Use exclusivamente o MCP server `figma`.
- Solicite contexto do design via ferramentas MCP.
- Não peça para tornar o arquivo público.
- Se houver falha, peça para o usuário autenticar o MCP ou verificar permissão no Figma.
