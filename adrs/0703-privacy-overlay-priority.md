# ADR-0703 — Prioridade de cookies

O onboarding não reconhecia cookies e o aviso cedia a outras superfícies. Usar Modal nativa existente para aviso e preferências, adiando outros diálogos até fechamento. Abrir não concede consentimento. Onboarding detecta a camada nativa antes de iniciar. Layout mobile-first preservado conforme capturas do usuário. Documentação Next embarcada indisponível no pacote instalado; nenhuma API Next alterada.
