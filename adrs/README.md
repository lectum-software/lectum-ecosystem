# ADRs Lectum

Este diretório registra decisões arquiteturais, decisões de produto com impacto técnico e execuções importantes de tasks.

Formato recomendado:

- título com número sequencial;
- status;
- contexto;
- decisão;
- consequências;
- task relacionada;
- validações.
