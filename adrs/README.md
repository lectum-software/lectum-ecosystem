# ADRs Lectum

Este diretório registra decisões arquiteturais, decisões de produto com impacto técnico e execuções importantes de tasks.

Formato recomendado:

- título com número sequencial;
- status;
- contexto;
- decisão;
- consequências;
- task relacionada;
- validações.

## Integridade

- Cada número pertence a um único documento.
- Todo documento numérico aparece exatamente uma vez neste índice.
- `pnpm check:adrs` bloqueia número duplicado, título divergente, arquivo ausente ou índice incompleto.
